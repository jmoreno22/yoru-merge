## Verdict

**CHANGES REQUESTED.**

Eight findings: one scope chain that prefers its narrowest rung and prints `OK` over three files, one
mechanical check that still compares an alias with itself, two holes in a brand-new gate — one of them
the exact defect the same wave fixed in the other script — one construction four sites short beside an
artefact declaring it complete, one class of figure the construction never looked for, one record
quoting a gate output inside the correction written for that defect, and one docblock claim about CI
that CI does not do.

**What is genuinely good in this wave, and should not be relitigated.** The graph hole is closed and
the check that says so is a command in CI. `DESIGN.md`'s false table is gone and its replacement
re-derives cell for cell. The figure gate has an exit code in every checkout shape anyone could build
and names the rung it used. The 23 → 2 marker migration is a net widening of what is recomputed, not a
trade for a pointer nobody verifies — three independent controls still redden. Registration is clean
over all 74 by two independent derivations. Nothing under `src/` moved, all five production md5s are
byte-identical, the whole battery is green, and **no finding in this round describes behaviour a user
would see**.

**What blocks is, for the fifth round running, the instrument certifying more than it checks** — now
one layer down, in the instruments themselves. Round 18 found D4's check comparing a function with
itself; the repair moved the comparison one line and left the two names pointing at the same array.
Round 18 found the graph check written and not run; the repair made it a command and gave it a comment
path it cannot see. Round 18 found D3 written and not performed; the repair performed most of it and
then wrote into `spec.md:264` that it was complete. Round 18 found the gate unable to run in CI; the
repair made it runnable and gave it a rung that runs over three files and calls that the branch.

**The transferable rule this round produces, and the reason D4 was decided as it was:** *after
building a check, attack it at the site the defect would actually appear, not at the site the last
review's reconstruction used* — and when the check is a script, that attack belongs in a test file,
not in a task record. Every one of these eight is a real fix that stopped one indirection short of the
thing it was aimed at, and then said so in the past tense. Three reconstructions per instrument is
what a wave can sustain by hand; twenty-four is what the defect needs, and twenty-four only fits in a
suite.
