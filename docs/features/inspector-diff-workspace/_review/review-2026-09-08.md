## Post-review finding — the gate itself was not deterministic (T43)

Found by the lead **after** this record's first draft, while running T40's RED step, and recorded here because it changes how every number above should be read.

Under vitest's default file-level parallelism the suite is not deterministic. On `228ab35` — the tree round 8 passed as «831 green» — with `src` byte-clean:

| run | parallel (as shipped) | serial (`fileParallelism: false`) |
|---|---|---|
| 1 | 1 failed / 830 passed | **831 passed** |
| 2 | **831 passed** | **831 passed** |
| 3 | 4 failed / 827 passed | **831 passed** |

Three runs at HEAD behaved the same way. The affected specs are the five that wait on an asynchronous render — `commit-list.spec.ts` AC-08 (the T27 focus-restore row), `main-content.spec.ts` AC-06, `diff-workspace.spec.ts` AC-06, `working-changes.spec.ts` AC-13 and `commit-inspector.spec.ts` AC-01 — all of them dependent on `afterNextRender`, the CDK `DomPortal` or the virtual viewport landing inside a window a competing fork can take away. **No `node`-environment spec failed in any of nine runs**, so the pure-TypeScript tier was never affected.

**What it costs this record and the three before it.** Every «831 green» in rounds 6–9 was measured under parallelism, so those were lucky runs rather than proof of a green suite. Three things survive unharmed:

- **The named single-point mutations.** Each reddened a specific row that matched the mutation, and the flaky set is a different, identifiable family. Round 8's «both reviewers agree on every value» holds for the same reason — they agreed on the *named* failures.
- **R9-S2-F1 and R9-S2-F2**, whose evidence is literally «the mutation leaves 831/831 green», were re-measured **serially** at pristine HEAD before any fix landed: both mutations still leave 831/831 green. The findings stand, now on a deterministic gate.
- **The 831 → 831 count anomaly** above is arithmetic over static counts, not a timing measurement.

What does *not* survive is the confidence any of those rounds expressed in a single green run. The fix is T43, one line in `vitest.config.ts` carrying the measurement, at about twelve seconds a run. It is deliberately **not** the root repair — making the five specs render-deterministic is — and the owner weighed that and chose the safety net now, with the root repair left to a future round. Rounds 6–8's records are not rewritten (round 7, S4).
